# GALLa Execution Guide

## Overview

GALLa training has two stages:

| Stage | What it trains | Data needed |
|-------|---------------|-------------|
| Stage 1 (Pretrain) | GNN + Adapter (LLM frozen) | Graph data (`node_ids`, `edge_index`, `source`) |
| Stage 2 (Finetune) | GNN + Adapter + LLM via LoRA | Graph QA data + Downstream task data |

---

## Folder Structure

```
GALLa/
  data/
    pretrain/
      Java_DFG.jsonl        # graph data for Stage 1 and Stage 2 graph QA generation
      Java_AST.jsonl
    train.buggy-fixed.buggy  # Java bug-fix source for Stage 2 downstream
    train.buggy-fixed.fixed
  data_sample/
    pretrain_test/
      pretrain.jsonl         # small sample for Stage 1 test run
    instruction_graph.jsonl  # generated by instruction_text.py
    instruction_downstream.jsonl  # generated by instruction_text.py
  configs/
    config_pretrain.json         # Stage 1 full run config
    config_pretrain_test.json    # Stage 1 test run config
    config_instruction.json      # Stage 2 full run config
    config_instruction_test.json # Stage 2 test run config
```

---

## Stage 1 — Graph Pretrain

### Test Run (small sample)

**Data:** Place 50–100 samples in `data_sample/pretrain_test/pretrain.jsonl`
Each line must have: `node_ids`, `edge_index`, `source`

**Config:** `configs/config_pretrain_test.json`
```json
{
  "data_dir": "data_sample/pretrain_test",
  "num_train_epochs": 3,
  "checkpointing_steps": 25
}
```

**Run:**
```bash
accelerate launch --config_file accelerate_ds_config.yaml run.py --train_config configs/config_pretrain_test.json
```

**Output:** `output/test/qwen2.5-coder-1.5b/final_step_X`

---

### Full Run

**Data:** Place all graph JSONL files in `data/pretrain/`
(e.g., `Java_DFG.jsonl`, `Java_AST.jsonl`, `Python_DFG.jsonl`, `Python_AST.jsonl`)

**Config:** `configs/config_pretrain.json`
```json
{
  "data_dir": "data/pretrain",
  "num_train_epochs": 3,
  "checkpointing_steps": 500
}
```

**Run:**
```bash
accelerate launch --config_file accelerate_ds_config.yaml run.py --train_config configs/config_pretrain.json
```

**Output:** `output/qwen2.5-coder-1.5b/final_step_X`

## Stage 2 — Instruction Finetuning

### Prepare Data (both test and full run)

Generate `instruction_graph.jsonl` and `instruction_downstream.jsonl` by running:

```bash
python3 instruction_text.py
```

This script:
- Reads graph files from `data/pretrain/` (auto-detects available Java/Python DFG/AST files)
- Reads bug-fix pairs from `data/train.buggy-fixed.buggy` and `data/train.buggy-fixed.fixed`
- Saves both output files to `data_sample/`

Key parameters in `instruction_text.py`:
```python
max_rows = 50        # rows read per graph file (increase for full run)
max_downstream = 50  # number of Java bug-fix samples (increase for full run)
```

For a **test run**: keep `max_rows = 50`, `max_downstream = 50`
For a **full run**: set `max_rows = 5000`, `max_downstream = 5000` (or remove the limit)

---

### Test Run

**Config:** `configs/config_instruction_test.json`
```json
{
  "data_dir": "data_sample",
  "checkpoint": "output/test/qwen2.5-coder-1.5b/final_step_X",
  "num_train_epochs": 1,
  "checkpointing_steps": 430
}
```

> Replace `final_step_X` with the actual folder name from Stage 1 output.

**Run:**
```bash
accelerate launch --config_file accelerate_ds_config.yaml run.py --train_config configs/config_instruction_test.json
```

**Output:** `output/test/instruction/qwen2.5-coder-1.5b/final_step_X`

---

### Full Run

**Config:** `configs/config_instruction.json`
```json
{
  "data_dir": "data_sample",
  "checkpoint": "output/qwen2.5-coder-1.5b/final_step_X",
  "num_train_epochs": 3,
  "checkpointing_steps": 1000
}
```

**Run:**
```bash
accelerate launch --config_file accelerate_ds_config.yaml run.py --train_config configs/config_instruction.json
```

**Output:** `output/instruction/qwen2.5-coder-1.5b/final_step_X`
This is your final fine-tuned model ready for inference.

## Monitoring Training

TensorBoard logs are saved to the `tb_dir` specified in the config.

To view:
```python
# In Colab
%load_ext tensorboard
%tensorboard --logdir /content/GALLa/output/test  # shows both Stage 1 and Stage 2
```

Metrics tracked:
- `training_loss` — loss on graph QA data
- `training_loss_ft` — loss on downstream task data (Stage 2 only)
- `eval_loss` — validation loss
- `perplexity` — validation perplexity (lower is better)
- `learning_rate` — LR schedule

## Inference

After Stage 2, load the final model like any standard Hugging Face model:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("output/instruction/qwen2.5-coder-1.5b/final_step_X")
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-Coder-1.5B")

prompt = "# Fix the bug in the following Java program\n\n# Buggy\n<your code>\n\n# Fixed\n"
inputs = tokenizer(prompt, return_tensors="pt")
output = model.generate(**inputs, max_new_tokens=256)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```

> Use the same prompt format as used in `instruction_downstream.jsonl` during training for best results.
